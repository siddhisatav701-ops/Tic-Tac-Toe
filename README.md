# Tic Tac Toe

A simple two-player Tic Tac Toe game that runs in your browser. Players take turns marking a 3x3 grid with O and X. The game announces a winner or a draw and lets you start a new round.

## Features

- Two-player, turn-based gameplay
- Win detection for rows, columns, and diagonals
- Draw detection
- Reset and new-game controls
- No dependencies or build tools required

## Run the game

1. Clone or download this repository.
2. Open `index.html` in a web browser.

## How to play

Click an empty square to place your mark. O goes first, then X. Complete a row, column, or diagonal of three marks to win. If all nine squares are filled without a winner, the game ends in a draw. Use **Reset Game** or **New Game** to play again.
